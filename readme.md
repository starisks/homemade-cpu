# My little CPU emulator
This is my CPU emulator, i don't know why. I just want it to exist on as much programming languages as possible. The CPU emulator is kind of realistic, it has multiple instructions. It started as a thought in my mind. "Why not make a CPU?" I thought. Then i made the Python port. Then i got bored. Then i thought "Why not make the C++ version?". So i made the C port. Then i got bored again. And now i have made the JavaScript port. and in the future, i will make the Go port, then the Lua port, then the Java port. And at the very last, the C# port.
